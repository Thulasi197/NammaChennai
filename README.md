# Namma City

Namma City is a Python Tkinter application for reporting and managing local civic issues.

## How it works

1. Citizens submit an issue with its category, location, description, and optional photo.
2. The app records the complaint and gives it a suggested priority.
3. Citizens can track the complaint and share a rating or feedback.
4. Staff use the separate dashboard to review complaints and feedback, assign workers, and update issue status.
5. Both applications save and share their data locally.

## Run the applications

Run these commands from PowerShell in the project folder:

```powershell
py NammaCity_Tkinter.py
py NammaCity_Staff.py
```
